# MahaMove AI 🚦

### AI-Powered Transportation & Mobility Management Platform for Mahakumbh

MahaMove AI is a smart mobility management platform developed for the **Mahakumbh Transportation & Mobility Management Hackathon**. It helps pilgrims and authorities make better transportation decisions through intelligent route planning, congestion prediction, crowd monitoring, parking recommendations, and real-time analytics.

---

## ✨ Features

- 🗺️ Smart Route Recommendation
- 🔥 Real-Time Crowd Heatmaps
- 🅿️ Smart Parking Allocation
- 📈 Congestion Prediction
- 🤖 AI Operations Copilot
- 📊 Interactive Analytics Dashboard

---

## 🛠️ Tech Stack

| Category | Technologies |
|----------|-------------|

| Backend | Next.js API Routes |
| Database | Supabase |

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Raushik-7/mahamove-ai.git
cd mahamove-ai
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

# DiscoverYourHome 🏠
A web-based application to predict house prices across India using Machine Learning models.  
Built with Streamlit, Flask, Firebase, and Google Maps API for an interactive and data-driven experience.
## ✨ Features
- Predict house prices using Random Forest ML model.
- Data preprocessing with Pandas and NumPy.
- Similarity-based recommendation system with Scikit-learn.
- Streamlit UI for interactive predictions.
- Flask backend with Firebase database.
- Google Maps API integration for location visualization.
- ## 🛠 Tech Stack
- **Languages:** Python, HTML, CSS, JavaScript
- **Libraries:** Pandas, NumPy, Scikit-learn
- **Frontend:** Streamlit
- **Backend:** Flask
- **Database:** Firebase
- **API Integration:** Google Maps
